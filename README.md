## 🌟 Overview

`nubsuki.exe` is a responsive portfolio built with modern vanilla web technologies and a dark monospace aesthetic.

---

## ✨ Features

- **Live Minecraft Server Widget**
- **Live Discord Presence**
- **Snaps (Photography Log)**
- **Open Benchmark Datasets**
- **Minimal & Modern Cyber Design**

---

---

## 🛠️ Built With

- **HTML5 & Vanilla JavaScript**
- **Vanilla CSS**
- **[Fira Code](https://fonts.google.com/specimen/Fira+Code)**: Monospace typography.
- **[Bootstrap Icons](https://icons.getbootstrap.com/)**: Clean vector iconography.
- **[Lanyard API](https://github.com/Phineas/lanyard)**: Live Discord presence and activity tracking.
- **[mcsrvstat.us](https://mcsrvstat.us/)**: Minecraft server status API.
- **Google UserContent CDN**: Direct photo delivery from Google Drive.
